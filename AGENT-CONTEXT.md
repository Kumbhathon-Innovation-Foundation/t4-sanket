# Anubhav — Agent Context

This repository is an MVP for Anubhav.

The system has three future interfaces:

1. Admin Operations Control Room
2. Pilgrim App/Web
3. KISKO public assistance kiosk

The Admin is currently being developed first because it provides the operational data foundation.
